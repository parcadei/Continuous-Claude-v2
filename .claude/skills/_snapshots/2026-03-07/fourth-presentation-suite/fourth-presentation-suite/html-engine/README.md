# HTML Engine (Bundled from frontend-slides)

This directory contains the HTML presentation engine used for **Phase 1** of the two-phase EBR workflow.

## What's Here

| File | Purpose |
|------|---------|
| `themes/midnight-executive.html` | HTML theme template — dark gradient design with Fourth brand colors |
| `components/midnight-components.html` | Interactive component library (Alpine.js, Chart.js) |
| `components/README.md` | Component usage patterns and API reference |
| `STYLE_PRESETS.md` | 10 named style presets for quick theming |

## Usage

During **Phase 1 (HTML Design Review)**, read `themes/midnight-executive.html` as the starting template. Use the component library for interactive elements like charts and data tables.

After the CSM approves the HTML preview, proceed to **Phase 2 (PPTX Conversion)** using the scripts in `../scripts/`.

## Authoritative Guide

All workflow instructions, brand rules, and layout decisions are in the parent **SKILL.md**. This directory provides the raw templates — SKILL.md tells you how and when to use them.
