# Fourth Presentation Layout Catalog v2

Prescriptive layout selection guide. Each layout includes **When to use**, **When NOT to use**, **Background**, **Typography**, and **Example content**. Use this to match content to the correct visual format.

---

## 1. Title Slide

**When to use:** Always the first slide. Sets tone and context.

**When NOT to use:** Never skip. Every deck opens with a title slide.

| Property | Value |
|----------|-------|
| Background | Vignette gradient (25deg, Teal -> Sky Blue -> Deep Blue) |
| Title | 48pt Poppins SemiBold, White, centered |
| Subtitle | 24pt Poppins Regular, White |
| Additional | Presenter name, date (14pt) |
| Logo | White version, top-right |

**Example:**
```
Title: "Transforming Workforce Management"
Subtitle: "Q4 2026 Executive Business Review"
Presenter: "Sarah Chen, VP Product -- October 2026"
```

---

## 2. Section Break

**When to use:** Between major topic shifts. Every 4-5 content slides in decks of 10+. Creates breathing room and signals a new topic.

**When NOT to use:** Between slides on the same topic. Never for content -- keep section breaks text-minimal.

| Property | Value |
|----------|-------|
| Background | Gradient (Deep Blue to Teal) or solid Deep Blue |
| Title | 60-80pt Poppins SemiBold, White, centered |
| Subtitle | 18pt Poppins Regular, White (optional) |
| Design | Full-bleed, no content chrome, no bullets |

**Example:**
```
Title: "Customer Impact"
Subtitle: "Real results from real operations"
```

---

## 3. Full-Slide KPI

**When to use:** A single metric deserves maximum visual impact. The number IS the slide. Use for the most important stat in a section (revenue, cost reduction, satisfaction score).

**When NOT to use:** When the number needs extensive context. When you have 2+ metrics (use KPI Grid instead). When the number isn't impressive on its own.

| Property | Value |
|----------|-------|
| Background | Dark navy with teal glow accent area |
| Category label | 12pt Poppins SemiBold UPPERCASE, Teal |
| Metric value | 72-96pt Poppins Bold, White |
| Metric label | 18pt Poppins Regular, Cool Grey |
| Context line | 14pt, below the label (e.g., "vs. 18% industry average") |

**Example:**
```
Category: "ROI"
Value: "23%"
Label: "Cost Reduction"
Context: "vs. 12% industry average"
```

---

## 4. KPI Card Grid

**When to use:** 2-4 related metrics that form a scorecard or dashboard view. Quarterly results summary, multiple KPIs from one initiative, performance dashboard.

**When NOT to use:** For a single dominant metric (use Full-Slide KPI). For more than 4 metrics (split across slides). When metrics are unrelated.

| Property | Value |
|----------|-------|
| Background | Dark navy or Midnight Navy |
| Layout | 2x2 grid (4 metrics) or 1x3 row (3 metrics) |
| Card background | Semi-transparent white (10-15% opacity) or solid Deep Blue |
| Value | 36-48pt Poppins Bold, White |
| Label | 14pt Poppins Regular, Cool Grey |
| Change indicator | Green (+) / Red (-) arrow, 12pt |

**Example:**
```
Card 1: "23%" / "Cost Reduction" / "+5% YoY"
Card 2: "$2.1M" / "Revenue" / "+15% YoY"
Card 3: "94%" / "Satisfaction" / "+3pts"
Card 4: "230" / "New Locations" / "+40%"
```

---

## 5. Single Column Content

**When to use:** ONLY when content is truly narrative and cannot be expressed as metrics, charts, quotes, or comparisons. Last resort layout.

**When NOT to use:** When content contains numbers (use KPI or chart). When content has a quote (use Pull-Quote). When content compares things (use Comparison or Matrix Table).

| Property | Value |
|----------|-------|
| Background | White or Soft White (#F5F5F5) |
| Category label | 12pt Poppins SemiBold UPPERCASE, Teal |
| Title | 36pt Poppins SemiBold, Deep Blue |
| Bullets | 18pt Poppins Regular, Dark Gray, Teal bullet markers |
| Max bullets | 4 (hard limit) |
| Max words per bullet | 8 (hard limit) |

**Content rules:**
- Follow the 4x8 rule: max 4 bullets of max 8 words each
- If exceeding limits, split across slides or use a different layout
- Teal accent line below title

**Example:**
```
Category: "PLATFORM OVERVIEW"
Title: "Why Teams Choose Fourth"
Bullets:
  - "Unified platform for all workforce needs"
  - "Real-time visibility across every location"
  - "AI-powered scheduling that adapts daily"
  - "Proven labor cost reduction at scale"
```

---

## 6. Pull-Quote

**When to use:** Customer testimonials, powerful statements from executives, any quote that deserves visual emphasis. Breaks up slide rhythm with a distinctive visual.

**When NOT to use:** For generic text. For your own marketing copy (use Problem Slide for bold claims). For quotes longer than 3 sentences.

| Property | Value |
|----------|-------|
| Background | Midnight Navy (#002747) |
| Teal accent bar | Vertical, left edge, 4px wide |
| Quote text | 28pt Poppins Regular, White |
| Attribution | 14pt Poppins SemiBold, Teal |
| Role/company | 14pt Poppins Regular, Cool Grey |

**Example:**
```
Quote: "Fourth completely changed how we schedule our 200+ staff across 12 locations."
Attribution: "Maria Torres"
Role: "Operations Director, Coastal Dining Group"
```

---

## 7. Problem Statement

**When to use:** A single powerful claim, question, or problem statement. Use to set up the "why" before presenting solutions. Creates dramatic pause in the deck flow.

**When NOT to use:** For content that needs supporting detail. For slides with multiple points. When the statement isn't provocative or bold enough.

| Property | Value |
|----------|-------|
| Background | Midnight Navy or Deep Blue, solid |
| Text | 36-48pt Poppins SemiBold, White, centered |
| Layout | One sentence, maximum two lines, centered vertically |
| Supporting | Optional small context line (14pt, Cool Grey) below |

**Example:**
```
Statement: "68% of restaurant managers spend 8+ hours per week on scheduling alone."
Context: "Source: Fourth Workforce Intelligence Report, 2026"
```

---

## 8. Before/After (Comparison)

**When to use:** Showing transformation, improvement, or contrast between two states. Implementation results, process improvements, before/after metrics.

**When NOT to use:** When comparing more than 2 states. For feature matrices (use Matrix Table). When the contrast isn't visually clear.

| Property | Value |
|----------|-------|
| Background | Soft White |
| Layout | Two equal columns with clear visual divider |
| Left ("Before") | Muted treatment -- Cool Grey accent, lighter text |
| Right ("After") | Teal accent highlight, bolder numbers |
| Title | Spans full width, states the transformation |
| Divider | Vertical teal line or arrow between columns |

**Example:**
```
Title: "Scheduling Transformation at Coastal Dining"
Before: "Manual process, 8 hrs/week, 73% adherence, high turnover"
After: "AI-powered, 45 min/week, 92% adherence, retention up 25%"
```

---

## 9. Two Column

**When to use:** Text paired with image, side-by-side information, or content that naturally divides into two parts.

**When NOT to use:** For before/after (use Comparison instead -- it has visual contrast built in). When columns are very unbalanced in content.

| Property | Value |
|----------|-------|
| Background | White or Soft White |
| Title | 36pt Poppins SemiBold, Deep Blue, full width |
| Columns | 50/50 or 60/40, with gutter |
| Content | Bullets or body text per column |

**Variants:** Text/Text, Text/Image, Image/Text, Problem/Solution

---

## 10. Three Column

**When to use:** Feature highlights (3 pillars), team profiles, stat callouts, service tiers. Content must be parallel in structure.

**When NOT to use:** When content isn't parallel across columns. For more than 3 items (split across slides). For detailed content that needs more space.

| Property | Value |
|----------|-------|
| Background | White or Soft White |
| Column structure | Icon/placeholder + H4 heading + 1-2 line description |
| Accent | Teal icons or Deep Blue icon containers |
| Parallel structure | Required -- all three columns must match format |

**Example:**
```
Title: "Three Pillars of Fourth"

[Clock]              [Chart]              [People]
"Scheduling"         "Analytics"          "Engagement"
"AI-powered shifts"  "Real-time data"     "Team communication"
```

---

## 11. Data / Chart Slide

**When to use:** Quantitative data, trends, comparisons. Any time you have numbers that tell a story better as a visual.

**When NOT to use:** For a single metric (use KPI). For qualitative comparisons (use Matrix Table).

| Property | Value |
|----------|-------|
| Background | White (clarity is paramount) |
| Title | 36pt Poppins SemiBold, Deep Blue -- states the INSIGHT, not the topic |
| Chart area | Center, 60-70% of slide |
| Legend | Bottom, 12pt Poppins Regular |
| Source | 12pt, bottom of slide |

**Chart type selection:**

| Data Shape | Chart Type |
|-----------|-----------|
| Comparing categories | Bar (vertical) or Column |
| Ranking with long labels | Bar (horizontal) |
| Trends over time | Line with markers |
| Part-of-whole (2-5 parts) | Donut |
| Composition comparison | Stacked bar |
| Before/after numeric | Grouped column |

**Color cycle:** Deep Blue, Teal, Sky Blue, Purple, Hot Red (in that order).

**Title rule:** State the insight: "Labor Costs Dropped 12% in Q3" not "Labor Cost Data"

---

## 12. Matrix Table

**When to use:** Feature comparisons, competitive analysis, capability matrices. Any grid of features with check/cross/partial indicators.

**When NOT to use:** For raw data tables (use standard Table). For few items that could be bullet points. For purely numeric data (use charts).

| Property | Value |
|----------|-------|
| Background | White |
| Header row | Deep Blue background, White text |
| Check marks | Teal checkmark or filled circle |
| Cross marks | Cool Grey X or empty circle |
| Partial | Sky Blue half-fill or "Partial" text |
| Row shading | Alternating White / Soft White |

**Example:**
```
Headers: ["Feature", "Fourth", "Competitor A", "Competitor B"]
Rows:
  ["AI Scheduling", check, cross, partial]
  ["Real-time Analytics", check, check, cross]
  ["Mobile App", check, check, check]
  ["Demand Forecasting", check, cross, cross]
```

---

## 13. Table Slide

**When to use:** Structured data that needs exact values visible. Financial summaries, pricing tiers, detailed metrics.

**When NOT to use:** For feature comparisons (use Matrix Table). For data that tells a better story as a chart. For more than 5 columns or 8 rows.

| Property | Value |
|----------|-------|
| Background | White |
| Header | Deep Blue bg, White Poppins SemiBold 14pt |
| Data rows | Alternating White / Soft White, Midnight Navy text |
| Numbers | Right-aligned |
| Text | Left-aligned |
| Key row highlight | Teal background |

---

## 14. Image Slide

**When to use:** Photography, product screenshots, venue images. When a visual tells the story better than text.

**When NOT to use:** For decorative images that don't support the narrative. For small images that don't fill the space.

| Variant | Description |
|---------|------------|
| Full-bleed | Image covers slide, text overlay with scrim |
| Image + Caption | Image 70%, caption below |
| Image + Text | 60/40 split |

**Scrim for readability:** `rgba(0, 39, 71, 0.6)` (Midnight Navy at 60%)

---

## 15. Closing Slide

**When to use:** Always the last slide. Summary, CTA, thank you.

**When NOT to use:** Never skip. Every deck ends with a closing slide.

| Property | Value |
|----------|-------|
| Background | Vignette gradient (mirrors title slide) |
| Title | 48pt Poppins SemiBold, White, centered |
| Content | 1-3 takeaways or next steps |
| Logo | White version, prominent |
| iQ callout | "Powered by iQ" in Teal or White |
| Contact | Email, URL (14pt) |

---

## 16. Stat Row

**When to use:** 2-4 KPIs with status context (good/watch/action). Quarterly scorecards, performance dashboards where each metric needs a traffic-light indicator.

**When NOT to use:** For a single dominant metric (use Full-Slide KPI). For metrics without a status dimension (use KPI Card Grid). For more than 4 metrics (split across slides).

| Property | Value |
|----------|-------|
| Background | Dark navy radial gradient |
| Category label | 12pt Poppins SemiBold UPPERCASE, Teal |
| Headline | 36pt Poppins SemiBold, White |
| Card layout | Horizontal row, centered, max 4 glass cards |
| Card value | 48pt Poppins Bold, White |
| Card label | 12pt Poppins Regular, Cool Grey |
| Status border | Teal (good), Amber (watch), Red (action) with glow |

**Example:**
```
Label: "PERFORMANCE OVERVIEW"
Headline: "Key Metrics This Quarter"
Stats: [94% Satisfaction (good), $2.1M Revenue (good), 68% Fill Rate (watch)]
```

---

## 17. Outcome Slide

**When to use:** A headline metric supported by narrative context and a trend chart. Pilot results, ROI proof points, outcome stories where the number AND the trend matter.

**When NOT to use:** When the metric has no supporting narrative (use Full-Slide KPI). When there is no trend data (use KPI Card Grid). When you need multiple metrics (use Stat Row).

| Property | Value |
|----------|-------|
| Background | Dark navy radial gradient |
| Zone A (1.1"-2.9") | Left 40%: 72pt stat + 18pt label. Right 60%: 36pt headline + 14pt body |
| Zone B (3.0"-5.85") | Full-width gradient area chart (teal to transparent) |
| Zone C (6.0"-6.7") | Callout strip with teal accent bar |
| Stat value | 72pt Poppins Bold, White (max 6 chars) |
| Headline | 36pt Poppins SemiBold, White (max 50 chars, 2 lines) |
| Body | 14pt Poppins Regular, Cool Grey (max 120 chars) |

**Example:**
```
Label: "OUTCOME 01"
Stat: "+23%" / "Labour Cost Reduction"
Headline: "College Station Pilot Results"
Body: "SPLH improvement since forecast adoption."
Chart: SPLH trend over 4 months
Callout: "Replicating across 200+ locations saves $2.1M."
```

## 18. Dark Content

**When to use:** Narrative content that needs a premium dark treatment with optional sidebar highlights. Deep-dive explanations, feature showcases, strategic context where glass cards add structure.

**When NOT to use:** For simple bullet lists (use Single Column Content). For metric-heavy content (use KPI or Stat Row). For content that fits better as a table.

| Property | Value |
|----------|-------|
| Background | Dark navy radial gradient |
| Category label | 12pt Poppins SemiBold UPPERCASE, Teal |
| Headline | 36pt Poppins SemiBold, White (full width or 7" with sidebar) |
| Teal accent line | 2" wide, below headline |
| Body | 18pt Poppins Regular, Cool Grey. Bullets or prose. |
| Sidebar cards | Max 3 glass cards (4" wide), right side. Title (14pt Bold White) + body (14pt Cool Grey) |

**Example:**
```
Label: "WORKFORCE INTELLIGENCE"
Headline: "AI-Powered Scheduling Drives Results"
Body: "Our demand forecasting model adapts daily."
Cards: [Forecasting, Optimization, Compliance]
```

## 19. Gap Slide

**When to use:** Variance analysis between current state and target/best practice. Opportunity identification, improvement areas, audit findings.

**When NOT to use:** For positive results (use Outcome or Stat Row). For action plans (use Recommendation). For narrative context (use Dark Content).

| Property | Value |
|----------|-------|
| Background | Dark navy radial gradient |
| Category label | 12pt Poppins SemiBold UPPERCASE, Teal |
| Headline | 36pt Poppins SemiBold, White |
| Table | Dark-themed: Deep Blue header, Midnight Navy rows |
| Columns | Area, Current, Best Practice, Gap |
| Gap column | Color-coded: Teal (good), Amber (watch), Red (action) |
| Max rows | 6 |

**Example:**
```
Label: "OPPORTUNITY AREAS"
Headline: "Where We Can Improve Together"
Gaps: Schedule Adherence 73% vs 92%, Labour Cost 32% vs 28%, Turnover 45% vs 35%
```

## 20. Recommendation Slide

**When to use:** Numbered action items with owners and timelines. Next steps, action plans, improvement recommendations.

**When NOT to use:** For commitments from both parties (use Mutual Commitments). For strategic roadmap items (use Roadmap). For simple bullet lists.

| Property | Value |
|----------|-------|
| Background | Dark navy radial gradient |
| Category label | 12pt Poppins SemiBold UPPERCASE, Teal |
| Headline | 36pt Poppins SemiBold, White |
| Action rows | Glass card background, max 5 rows |
| Number circle | Teal filled oval, 16pt Bold White |
| Action title | 18pt Poppins Bold, White |
| Description | 14pt Poppins Regular, Cool Grey |
| Timeline badge | Pill badge, right-aligned, teal 25% opacity |

**Example:**
```
Label: "RECOMMENDED ACTIONS"
Headline: "Next Steps to Accelerate ROI"
Actions: [1. Expand Forecast (Q1), 2. Manager Training (Q1), 3. Model Tuning (Q2)]
```

## 21. Mutual Commitments

**When to use:** Partnership close-out slide with commitments from both Fourth and the client. EBR/QBR final content slide before closing.

**When NOT to use:** For one-sided action items (use Recommendation). For strategic initiatives (use Roadmap). As a generic closing slide (use Closing).

| Property | Value |
|----------|-------|
| Background | Vignette gradient (premium closing feel) |
| Category label | 12pt Poppins SemiBold UPPERCASE, Teal |
| Headline | 36pt Poppins SemiBold, White, centered |
| Two columns | Glass cards with teal (Fourth) and sky-blue (Client) status borders |
| Column headers | 12pt Bold UPPERCASE, Teal / Sky Blue |
| Items | Teal checkmark + 14pt White text, max 5 per column |
| Divider | Thin white semi-transparent line below columns |
| Footer | "NEXT REVIEW" eyebrow + date (14pt Teal) + contact info (14pt Cool Grey) |

**Example:**
```
Label: "NEXT STEPS"
Headline: "Mutual Commitments"
Fourth: [Forecast rollout, GM training, QBR cadence]
Client: [Regional champions, Historical data, Executive sponsor]
Next Review: "March 28, 2026"
```

## 22. Roadmap Slide

**When to use:** Strategic initiatives relevant to the client. Product roadmap items, upcoming features, investment areas where relevance to the client is key.

**When NOT to use:** For immediate action items (use Recommendation). For commitments (use Mutual Commitments). For more than 4 items (split across slides).

| Property | Value |
|----------|-------|
| Background | Dark navy radial gradient |
| Category label | 12pt Poppins SemiBold UPPERCASE, Teal |
| Headline | 36pt Poppins SemiBold, White |
| Pill badge row | Max 4 pills below headline (solid or outline style) |
| Cards | Left-accent glass cards (teal bar), max 4 stacked |
| Card title | 16pt Poppins Bold, White |
| Card description | 14pt Poppins Regular, Cool Grey |
| "Relevant because:" | 12pt Bold Teal label + 12pt Grey text |
| Timeline badge | Outline pill, right-aligned per card |

**Example:**
```
Label: "ROADMAP RELEVANCE"
Headline: "What's Coming That Matters to You"
Pills: [AI/ML (solid), Mobile (outline), Analytics (outline)]
Items: [Forecasting v2 (Q2), Manager App (Q3)]
```

## Layout Sequencing

Alternate visual weight across a deck to maintain engagement:

```
HEAVY  -> Title (vignette)
LIGHT  -> Agenda (white)
MEDIUM -> Content (soft white)
HEAVY  -> KPI (dark navy)
LIGHT  -> Content (white)
HEAVY  -> Section Break (gradient)
MEDIUM -> Chart (white, but visual)
HEAVY  -> Quote (midnight navy)
LIGHT  -> Content (soft white)
HEAVY  -> Closing (vignette)
```

### Density Guidelines

| Deck Length | Required Mix |
|-------------|-------------|
| 5-8 slides | Title, 1-2 KPI, 1-2 Content, 1 Data/Chart, Closing |
| 10-15 slides | Title, Agenda, 2 Sections, 2-3 KPI, 2-3 Content, 1-2 Data, 1 Quote, Closing |
| 20+ slides | Title, Agenda, 3-4 Sections, 3-4 KPI, 4-5 Content, 2-3 Data, 2 Quotes, Closing |

**Rule:** In any deck with numeric claims, at least 30% of slides should use visual data formats (KPI, chart, table, comparison) rather than bullets.
