# Fourth Brand Color System

## Primary Palette

| Color | Hex | RGB | CMYK | Usage |
|-------|-----|-----|------|-------|
| Deep Blue | #0C4A7D | 12, 74, 125 | 90, 41, 0, 51 | Primary brand color, headers, key elements |
| Teal Green | #00B69F | 0, 182, 159 | 100, 0, 13, 29 | Accents, CTAs, highlights — represents AI intelligence |
| Sky Blue | #6fb4e3 | 111, 180, 227 | 51, 21, 0, 11 | Supporting elements, backgrounds, accent within vignette |

## Secondary Palette

| Color | Hex | RGB | Usage |
|-------|-----|-----|-------|
| Midnight Navy | #002747 | 0, 39, 71 | Use as black for text/bold highlights — NEVER as background |
| Dark Gray | #373e42 | 55, 62, 66 | Body text, secondary elements |
| Cool Grey | #CFD1D1 | 207, 209, 209 | Highlighting text sections — use Midnight Navy for text on it |
| Soft White | #F5F5F5 | 245, 245, 245 | Subtle backgrounds, separators |
| White | #FFFFFF | 255, 255, 255 | Backgrounds, contrast, clean space |

## Tertiary Palette (Use Sparingly)

- Sunrise Orange: #062A3C
- Hot Red: #d9373b
- Purple: #9279b2

## Color Usage Rules

**DO:**
- Deep Blue for primary brand presence
- Teal for CTAs and highlights
- Sky Blue for supporting visuals
- Midnight Navy as black alternative for text
- White space generously

**DON'T:**
- Introduce colors outside palette
- Overuse bright colors (Teal, Sky Blue)
- Use Midnight Navy as background or large areas
- Use Teal (#00B69F) for body text — fails contrast (2.4:1)
- Use color as sole differentiator (accessibility concern)

## Accessibility — WCAG 2.1

| Text Type | Minimum Contrast |
|-----------|-----------------|
| Body text | 4.5:1 |
| Large text (18pt+) | 3:1 |

**Palette compliance:**
- Deep Blue (#0C4A7D) on white: 12.7:1 — AAA compliant
- Midnight Navy (#002747) on white: strong contrast — AAA compliant
- Dark Gray (#373e42) on white: 10.8:1 — AAA compliant
- **Teal (#00B69F) on white: 2.4:1 — accents ONLY, NOT body text**
- Sky Blue (#6fb4e3) on white: graphics only, never body text

## Visual Elements

**Vignettes (Gradient Backgrounds):**
- 25-degree angle gradient: Teal (#00B69F) → Sky Blue (#6fb4e3) → Deep Blue (#0C4A7D)
- Represents dynamic movement and energy of Fourth with iQ
- Can be tinted to white for subtle background effect

**Graphic Backgrounds:**
- Flowing line patterns representing data movement and connections
- Can be colored or monochromatic
- Tint back if used behind text for readability

**Icon Patterns:**
- Fourth icon as background pattern
- White tint on colored backgrounds
- Deep Blue tint on white backgrounds
