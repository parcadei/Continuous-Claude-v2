# Fourth Typography System

## Primary Font: Poppins

Geometric sans-serif. Modern and approachable. Excellent readability (print and digital). Wide weight range (Thin to Black).

## Type Hierarchy

| Element | Weight | Size |
|---------|--------|------|
| H1 | Semibold | 48pt |
| H2 | Semibold | 36pt |
| H3 | Semibold | 24pt |
| H4 | Semibold | 20pt |
| Body (primary) | Regular | 16pt |
| Body (secondary) | Regular | 14pt |
| Captions/footnotes | Regular | 12pt |

- Line height: 1.5x for body text
- Emphasis: Poppins Medium or Semibold (not italic)
- Quotes: Poppins Regular, 18pt (italic acceptable)
- Code/Technical: Poppins Regular or system monospace

## Rules

**DO:**
- Use Poppins for all text
- Maintain consistent hierarchy
- 1.5x line height minimum
- Left-align body text; center-align headlines selectively
- Bold for emphasis

**DON'T:**
- Mix multiple font families
- Use ALL CAPS for paragraphs
- Use decorative or script fonts for body text
- Underline text (use bold instead)
- Go below 14pt for body text

## Quote Styling

Use elements from the Fourth icon to frame quotes:
- Icon corner elements in Teal or Deep Blue
- Clean framing that draws attention without overwhelming
