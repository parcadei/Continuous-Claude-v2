# Fourth Brand Standards Reference

## Color Palette

### Primary Colors

| Name | Hex | RGB | Usage |
|------|-----|-----|-------|
| Deep Blue | `#0C4A7D` | 12, 74, 125 | Headers, navigation, key elements, brand presence |
| Teal Green | `#00B69F` | 0, 182, 159 | Highlights, CTAs, accents — iQ signature color |
| Sky Blue | `#6fb4e3` | 111, 180, 227 | Accent within vignette, iQ energy and movement |

### Secondary Colors

| Name | Hex | RGB | Usage |
|------|-----|-----|-------|
| Midnight Navy | `#002747` | 0, 39, 71 | Use as black for text and bold highlights |
| Cool Grey | `#CFD1D1` | 207, 209, 209 | Highlighting sections of text |
| Soft White | `#F5F5F5` | 245, 245, 245 | Versatile background color |
| Dark Gray | `#373E42` | 55, 62, 66 | Body text, secondary text elements |

### Tertiary Colors (Use Sparingly)

- Sunrise Orange `#062A3C`
- Hot Red `#d9373b`
- Purple `#9279b2`

### Color Usage Rules

**DO:**
- Use Sky Blue and Teal Green as accent/highlight colors
- Use Midnight Navy and Deep Blue for headers, navigation, structure
- Use Cool Grey and Soft White as neutral backgrounds
- Maintain color meaning consistently across slides

**DON'T:**
- Introduce new colors outside approved palette
- Use teal (#00B69F) for body text — fails contrast (2.4:1 ratio)
- Use Midnight Navy as background or across large areas
- Use white text on Cool Grey (use Navy instead)

### Logo Color Rules

| Background | Logo Variant |
|-----------|--------------|
| White or Soft White (#F5F5F5) | Standard (Deep Blue + Teal iQ) |
| Deep Blue (#0C4A7D) | Teal iQ element visible |
| Teal Green (#00B69F) | White logo version |

### Accessibility — WCAG 2.1 Contrast Ratios

| Color Pairing | Ratio | Status |
|---------------|-------|--------|
| Deep Blue on white | 12.7:1 | Excellent |
| Midnight Navy on white | ~15:1 | Excellent |
| Dark Gray on white | 10.8:1 | Excellent |
| Teal on white | 2.4:1 | Accents ONLY — not for text |
| Sky Blue on white | N/A | Graphics only, not text |

Minimums: body text (18pt or less) 4.5:1 · large text (18pt+ or 14pt+ bold) 3:1

## Typography System

**Font:** Poppins (all weights) — use for ALL PowerPoint text.

### Hierarchy

| Level | Style | Size |
|-------|-------|------|
| H1 — Slide Titles | Poppins Semibold | 48pt |
| H2 — Section Headers | Poppins Semibold | 36pt |
| H3 — Sub-sections | Poppins Semibold | 24pt |
| H4 — Minor Headers | Poppins Semibold | 20pt |
| Primary Body | Poppins Regular | 18pt |
| Secondary Body | Poppins Regular | 14pt |
| Captions | Poppins Regular | 12pt |
| Small Text | Poppins Regular | 10pt |

Line spacing: 1.21x · Max 12 words per line · Body text: left-align · Headlines: center when appropriate

### Typography Rules

**DO:** Maintain consistent hierarchy · Use Semibold for headings · Use Regular for body · Add 21% extra leading

**DON'T:** Mix font families · Use ALL CAPS in paragraphs · Underline text · Use italics for emphasis (use Semibold) · Text smaller than 14pt

## Slide Backgrounds

**Vignettes (Gradient):**
- 25-degree angle: Teal (#00B69F) → Sky Blue (#6fb4e3) → Deep Blue (#0C4A7D)
- Can be tinted back (11% white overlay) for subtle background use

**Graphic Backgrounds:**
- Flowing line patterns (data movement visualization)
- Tint back if used behind text

**Icon Patterns:**
- Fourth icon as background pattern
- White tint on colored backgrounds · Deep Blue tint on white backgrounds

## Photography Guidelines

### Staff Interacting with Software
- Real people in authentic hospitality settings
- Natural lighting, candid moments
- Diverse representation, device in hand

### Software Interface Showcase
- Person cut out against flat color background
- Head above colored shape edge, lower body within
- Technology as main focus

### Software In Situ
- Location context (kitchen, restaurant, hotel lobby)
- Color surround on photograph for differentiation

### Real People (Case Studies)
- Short depth of field (subject in focus, background blurred)
- Authentic expressions, environment shows work context

### Case Study Branding
- Customer product/venue photography
- Lozenge shape with customer logo
- Headline format: "[Customer Name] improved [outcome]"

## Quality Checklist

### Brand Compliance
- [ ] Using official 2025 Fourth template
- [ ] All colors from approved palette only
- [ ] Color usage follows rules (no teal for text, etc.)
- [ ] Poppins font used exclusively
- [ ] Fourth iQ spelled correctly (lowercase i, uppercase Q)
- [ ] Logo appears correctly on title slide

### Content Quality
- [ ] Bullet points follow 4x6 rule
- [ ] No typos or grammatical errors
- [ ] Clear messaging throughout
- [ ] Logical flow and structure
- [ ] Tone is energetic, insightful, human, confident

### Design Quality
- [ ] Appropriate template layouts selected
- [ ] Elements aligned to grid
- [ ] Consistent spacing maintained
- [ ] Adequate white space — not overcrowded
- [ ] Visual hierarchy clear

### Technical Quality
- [ ] All images high resolution (1920x1080 min for full-slide)
- [ ] File size reasonable (<50MB)
- [ ] Animations appropriate (if used)
- [ ] Works in PowerPoint and other viewers

### Accessibility
- [ ] Color contrast meets WCAG standards (4.5:1 body, 3:1 large)
- [ ] Text readable (14pt minimum, 18pt recommended)
- [ ] Alt text for images (when relevant)
- [ ] Clear visual hierarchy

## Common Pitfalls

### Color Mistakes
- Using teal (#00B69F) for body text
- Colors outside approved palette
- Midnight Navy (#002747) as background
- White text on Cool Grey

### Typography Mistakes
- Mixing fonts (Poppins only)
- Text below 14pt
- ALL CAPS in paragraphs
- Underlined text
- Inconsistent sizing for same hierarchy level

### Content Mistakes
- More than 6 bullet points per slide
- Bullets longer than 6 words
- Paragraphs of text on slides (move to speaker notes)
- Overcrowded slides

### Layout Mistakes
- Ignoring template placeholders
- Misaligned elements
- Inconsistent spacing between slides
- Content pushed to edges (ignoring margins)
