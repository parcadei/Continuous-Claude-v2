# Drift Categories

Classification of files that may differ between the continuous-claude repo and the active `~/.claude/` directory.

## Known Local-Only Files

These files are expected to differ or only exist in the active directory. They are machine-specific, contain secrets, or are auto-generated. Never report these as unexpected drift.

| File | Reason | Details |
|------|--------|---------|
| `settings.json` | Machine-specific configuration | Contains MCP server paths, model preferences, hook registrations. Paths differ per machine (e.g., `C:\Program Files\...`). The sync script merges `mcpServers` from repo into active but does not overwrite the full file. |
| `settings.local.json` | Local overrides | Optional per-machine overrides for settings.json. Never committed to repo. |
| `CLAUDE.md` | Private global instructions | User-specific instructions loaded at session start. Contains personal preferences and environment-specific config. Lives only in `~/.claude/`. |
| `RULES.md` | Private global rules | User-specific constraints and enforcement rules. Contains environment paths and personal workflow rules. Lives only in `~/.claude/`. |
| `extraction-state.json` | Hook extraction state | Tracks which insights have been extracted by the pre-compact hook. Per-machine, per-session state. Auto-generated. |
| `knowledge-tree.json` | Auto-generated project index | Generated by `knowledge_tree.py` for each project. Contains file structure and component maps. Regenerated on demand, not synced. |
| `.env` | Environment secrets | Database URLs, API keys, tokens. Never committed. |
| `.credentials.json` | Auth tokens | OAuth tokens, API credentials. Never committed. |
| `history.jsonl` | Session history | Local session log. Machine-specific, not synced. |

## Synced Directories

These directories ARE synced by `scripts/sync-to-active.sh` and differences here represent real drift.

| Directory | What Syncs | Exclusions |
|-----------|-----------|------------|
| `hooks/src/` | All TypeScript source files | `node_modules/`, `.tldr/`, `*.pid`, `*.lock` |
| `rules/` | All rule files (`.md`) | None |
| `skills/` | `SKILL.md` and `references/` per skill | `_eval/`, `_snapshots/`, `_sandbox/`, `cache/`, `node_modules/` |
| `agents/` | All agent definition files | None |

### Hook Root Files

These individual files in `hooks/` are also synced:

- `hooks/build.sh` -- build script (bash)
- `hooks/build.ps1` -- build script (PowerShell)
- `hooks/package.json` -- npm dependencies
- `hooks/tsconfig.json` -- TypeScript config

### What Does NOT Sync

| Item | Why Not Synced |
|------|----------------|
| `hooks/dist/` | Built locally via `npm run build`. Rebuild after sync. |
| `hooks/node_modules/` | Installed locally via `npm install`. Install after sync. |
| `hooks/cache/` | Runtime cache, per-machine |
| `skills/_eval/` | Evaluation tooling, not needed in active |
| `skills/_snapshots/` | Evaluation snapshots, not needed in active |

## Drift Classification Logic

When a file appears in a diff result:

1. **Check the local-only list above.** If the file is listed, classify as "known local-only" and skip it.
2. **Check if the file is in a synced directory.** If yes, it represents real drift.
3. **Check the direction:**
   - File in repo but not active = "missing in active" (run forward sync)
   - File in active but not repo = "missing in repo" (may be local creation, or run reverse sync)
   - File in both but differs = "content differs" (run forward sync to update active)
4. **Special case for hooks/dist/:** Compare timestamps of `.ts` source vs `.mjs` dist. If source is newer, classify as "stale build" (run `npm run build`).
